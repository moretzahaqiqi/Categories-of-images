# Categories-of-images
تعداد تصاویرت زیاده و می‌خوای دستی نریزی تو پوشه‌ها.
تصاویرت قبلاً طبقه‌بندی نشدن و فقط یه فولدر کلی از تصاویر داری.
می‌خوای هر 80 تصویر رو به صورت متوالی (تصویر 1 تا 80، 81 تا 160 و ...) برداره و بذاره توی یه پوشه با اسم‌هایی که دادی.
✅ هدف:
تقسیم تصاویر موجود در یک فولدر به چندین زیرفولدر به ترتیب.
هر زیرفولدر حداکثر 80 تصویر داشته باشد.
